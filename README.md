# Luxes Lexios — Landing page

## Como visualizar
1. Extraia o arquivo ZIP.
2. Mantenha `index.html`, `style.css`, `script.js` e a pasta `assets` juntos.
3. Abra `index.html` no navegador. Para desenvolvimento, você também pode usar a extensão Live Server do VS Code.

## Personalização
- Troque o texto do perfil em `index.html` pelos dados reais do proprietário.
- Substitua `assets/personagem-referencia.jpg` por outra imagem, mantendo o mesmo nome, se desejar.
- Altere `contato@seudominio.com` pelo e-mail real no link de contato.
- As cores principais ficam no início de `style.css`, nas variáveis `--bg`, `--blue` e `--cyan`.

A página usa HTML, CSS e JavaScript puro, com menu dropdown e navegação mobile responsiva.
